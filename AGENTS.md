# Touch Soil

An offline garden planner: an open-weight Gemma model (via WebLLM) runs entirely in the browser and turns a small climate dataset into a "what to plant this week" plan. Built for the DEV Hacktoberfest Open-Source AI Challenge, Week 1: Touch Grass.

For visual direction, read `DESIGN.md` (Linear-style dark theme, owner-supplied).
